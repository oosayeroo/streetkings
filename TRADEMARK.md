# StreetKings Trademark & Branding Policy

StreetKings is an open-source project created by **Envi-Scripts and
919DESIGN**.

The StreetKings source code is made available under the **Apache License
2.0**. We chose this licence because we want developers and server
owners to have the freedom to use StreetKings, modify it, extend it, and
build their own experiences on top of it.

However, open-source access to the StreetKings code does **not** grant
unrestricted rights to the **StreetKings name, logos, branding, visual
identity, or other brand assets**.

This policy explains that distinction.

------------------------------------------------------------------------

## 1. Open Source Code

The StreetKings source code is licensed separately under the **Apache
License 2.0**.

Subject to the terms of that licence, you are welcome to:

-   Use StreetKings to create your own FiveM server.
-   Modify and extend the StreetKings code.
-   Add your own features and systems.
-   Create derivative works based on the StreetKings code.
-   Redistribute the software in accordance with the Apache License 2.0.
-   Use StreetKings as the foundation for commercial or community
    projects where permitted by the licence.

We actively encourage developers to build upon StreetKings.

This Trademark & Branding Policy does **not** restrict the rights
granted to you under the Apache License 2.0.

------------------------------------------------------------------------

## 2. The StreetKings Brand

The Apache License 2.0 specifically does not grant permission to use the
trade names, trademarks, service marks, or product names of the licensor
except as required for reasonable and customary use in describing the
origin of the software.

Accordingly, permission to use the StreetKings source code does not
automatically grant permission to use the **StreetKings brand as the
identity of your own project, community, or server**.

This includes, where applicable:

-   The **StreetKings** name
-   StreetKings logos
-   StreetKings icons and brand marks
-   Official StreetKings artwork
-   StreetKings visual branding
-   Branding designed to closely imitate the official StreetKings
    identity
-   Other official StreetKings brand assets

------------------------------------------------------------------------

## 3. Community Servers

We love seeing communities build their own servers and experiences using
StreetKings.

Community servers should, however, establish their **own distinct name
and brand identity**.

You may freely and prominently explain that your server uses
StreetKings.

For example:

**Allowed:**

> Velocity Racing - Powered by StreetKings

> Apex Racing - Built on the StreetKings Framework

> NightShift - A Server Powered by StreetKings

> Powered by StreetKings

> Built using StreetKings

> Based on the StreetKings open-source framework

These descriptions identify StreetKings as the technology or framework
powering your project without implying that your project is operated by
the StreetKings team.

------------------------------------------------------------------------

## 4. Naming Community Servers

Please do not use **StreetKings as the primary name of your server or
community** without prior written permission.

For example, names such as:

-   StreetKings Italia
-   StreetKings UK
-   StreetKings Germany
-   StreetKings Europe
-   StreetKings RP
-   StreetKings Racing
-   StreetKings Community
-   StreetKings Official Italia
-   Official StreetKings UK

may reasonably give players the impression that the server is an
official, regional, authorised, endorsed, or otherwise affiliated
StreetKings service.

Instead, create your own identity and reference StreetKings as the
underlying framework.

For example:

**Instead of:**

> StreetKings Italia

**Use something like:**

> Italia Racing\
> Powered by StreetKings

This lets you benefit from identifying the framework your server is
built upon while maintaining a clear distinction between your community
and the official StreetKings project.

------------------------------------------------------------------------

## 5. StreetKings: Official Server

**StreetKings: Official Server** is the official first-party StreetKings
server operated by the StreetKings team.

Community projects using the open-source StreetKings framework are
independent projects unless we have expressly stated otherwise.

You must not represent or imply that your server, community, website,
Discord, social media account, or other service is:

-   An official StreetKings service
-   Operated by the StreetKings team
-   An official regional StreetKings server
-   Endorsed or approved by StreetKings
-   Sponsored by StreetKings
-   A partner of StreetKings
-   Otherwise officially affiliated with StreetKings

unless you have received explicit permission to make that claim.

------------------------------------------------------------------------

## 6. Logos & Visual Identity

Community projects should develop their own logos and visual identities.

Please do not use the official StreetKings logo as your project's
primary logo, avatar, server icon, website logo, or other identifying
mark without permission.

Similarly, please do not create branding which is so close to the
official StreetKings branding that users could reasonably mistake your
project for an official StreetKings service.

Referencing StreetKings to identify the framework powering your project
is welcome.

Imitating the official project's identity is not.

------------------------------------------------------------------------

## 7. "Powered by StreetKings"

We want community projects to be proud of building on StreetKings.

You are therefore welcome to use factual attribution such as:

> **Powered by StreetKings**

or:

> **Built on StreetKings**

to identify StreetKings as the underlying framework.

Where appropriate, we encourage linking **StreetKings** back to the
official StreetKings project.

Such attribution must not be presented in a manner that suggests your
project is operated, sponsored, endorsed, or officially affiliated with
StreetKings.

------------------------------------------------------------------------

## 8. Forks & Modified Versions

You are welcome to fork and modify the StreetKings source code in
accordance with the Apache License 2.0.

Where the Apache License requires notices, attribution, identification
of modifications, or other conditions to be preserved, those
requirements must continue to be followed.

A modified version or fork of StreetKings does not automatically become
an official StreetKings product simply because it originated from the
StreetKings source code.

If you substantially modify StreetKings and distribute it as your own
framework or product, we ask that you give the modified project its own
distinct name while retaining any attribution required by the Apache
License 2.0.

------------------------------------------------------------------------

## 9. No Additional Software Restrictions

This policy governs the **StreetKings brand and identity**, not the
open-source software rights granted by the Apache License 2.0.

Nothing in this policy is intended to revoke, reduce, replace, or modify
the permissions granted under the Apache License 2.0.

Where there is a distinction between:

**using the StreetKings software**

and

**using the StreetKings brand to identify your own service**

this policy addresses the latter.

------------------------------------------------------------------------

## 10. Permission

If you would like to use StreetKings branding in a way that falls
outside this policy, please contact the StreetKings team first.

We're open to collaborations, community projects, regional initiatives,
showcases, and other creative uses of StreetKings.

Permission should be obtained **before** representing a project as
officially affiliated with StreetKings.

------------------------------------------------------------------------

## 11. Questions

We're not looking to discourage people from building on StreetKings -
quite the opposite.

StreetKings is open source because we want people to take the framework,
modify it, improve it, and create entirely new experiences with it.

We simply ask that community projects maintain their **own identity** so
players can easily distinguish between:

**StreetKings itself, StreetKings: Official Server, and independent
projects powered by StreetKings.**

If you're unsure whether your use of the StreetKings name or branding is
appropriate, please contact us before launching it.
